# Weather App 🌤️

A simple, responsive weather app that shows current weather information for any city. Built using HTML, CSS, and JavaScript.  

**Live Demo:** [https://sandi-weather-app.netlify.app/](https://sandi-weather-app.netlify.app/)  

## Features
- Search the weather by city  
- Displays temperature, weather conditions, and location  
- Responsive design for desktop and mobile  

## Technologies
HTML | CSS | JavaScript
